# Barcelona Street Watch

Traffic accident analysis and visualization for Barcelona using MongoDB, Pandas, Matplotlib, and Folium.

<img src="project/images/banner.jpeg" alt="Barcelona StreetWatch banner"/>

This ETL project explores traffic accident data published by the City of Barcelona, queried via API and using MongoDB for data storage and Python+Pandas for analysis and visualization.

The analysis focuses on:

* Accident distribution across Barcelona
* Trends by date and time
* Geographic accident hotspots
* Patterns in accident frequency and type

The full analysis is available as an HTML page:

**[View Barcelona Street Watch](https://leinadher.github.io/Barcelona-StreetWatch/project/project-traffic_accidents.html)**

The project uses open traffic accident data provided by the City of Barcelona, and serves as a showcase of a MongoDB-based ETL setup.

* MongoDB
* Python
* Pandas
* Matplotlib
* Folium
* Jupyter Notebook
